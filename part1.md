# Розділ 1. Розробка вимог до системи та ПЗ

## 1.1. Загальний опис проектованої системи

Система спроектована для автоматизації освітлення тепличного комплексу для оптимізації використання електроенергії та для гарного росту рослин. Вона буде контролювати рівень освітлення.

## 1.2. Вимоги до функцій та завдань

система повинна виконувати такі функції

 1.Вимірювання поточного рівня природної освітлення за допомогою цієї системи,моніторинг стану,керування лампами, відображення даних на графічній панелі користувача Dashboard

 2.Автоматизоване увімкнення/вимкнення ламп в заданий час

 3.Виведення статистики в Google Sheet та на телеграм клієнт

## 1.3. Вимоги до видів забезпечення.

## Апаратне забезпечення

- Обчислювальний компонент: Мікрокомп'ютер Rasbery Pi моделі (3/4/5) або його налаштований віртуальний аналог.
- Датчики: аналогові/цифрові датчики освітлення (або імітаційний
  модуль для тестування edge-рівня).
- Периферія: макетна плата, світлодіоди, з'єднувальні дроти.
- Мережеве обладнання: Wi-Fi роутер із доступом до мережі Інтернет.

- Пристрій користувача: смартфон або планшет на базі Android/iOS.

### Програмне забезпечення

- Операційна система: Linux (Raspbian / Debian).


- Середовище розробки: Node-RED (з модулями node-red-dashboard).

- Система керування базами даних: MariaDB (локальна СКБД на Raspberry Pi)
- Хмарні сервіси: Google Sheets (для аналітики) та Google Sites (для відображення звітів).

- Комунікаційні сервіси: Telegram Bot API  для сповіщень.
- Мобільне ПЗ: клієнт Telegram.
